Recovery Ladder

1. Re-observe
Bangun occupancy grid baru dari frame terbaru.
2. Replan

3. Motion check
Bandingkan frame sebelum/sesudah input.
4. Unstuck
Back/strafe bergantian bila tidak ada displacement visual.
5. Abort
STUCK / PATH_UNREACHABLE dikirim ke Brain untuk retry/replan high-level.

MM2 Controls

AUTO membutuhkan role yang stabil sebelum behavior ofensif aktif.

Role Policies

Innocent
Survive, jaga jarak dari confirmed knife holder, terus observasi.
Sheriff / Hero
Survive lebih dulu; hanya menembak bila murderer confidence tinggi dan tidak ada friendly-fire overlap.
Murderer
Prioritaskan gun holder, melee saat dekat, knife throw saat jarak menengah, approach saat terlalu jauh.
Unknown
Tidak menyerang. Jika murderer terlihat, survival tetap boleh menghindar.

Combat Safety

Sheriff trigger discipline
Minimum murderer confidence 93% sebelum fire.
Crowd check
Tahan tembakan bila avatar lain overlap dengan aim point.
Cooldown
Gun/throw/melee punya local cooldown supaya input tidak spam.
Survival priority
Ancaman dekat diproses sebelum offense pada role non-Murderer.
